# 런퀘스트

개인 맞춤형 순환 러닝 코스를 추천하고, 기록과 업적을 공유할 수 있는 플러터 기반 러닝 앱 프로토타입입니다.

## 앱 개요

런퀘스트는 사용자가 처음에 다섯 가지 항목만 선택하면 출발 위치를 기준으로 러닝 코스를 추천합니다.

- 거리
- 경사
- 러닝 흐름
- 환경
- 안전 우선순위

기본 거리는 3킬로미터, 5킬로미터, 7킬로미터, 10킬로미터를 지원하며, 모든 코스는 출발 위치로 돌아오는 순환 코스를 기준으로 설계합니다.

## 주요 기능

- 야간 안전런, 페이스런, 업힐런, 힐링런, 10킬로미터 기록 도전 프리셋
- 보안등, 폐쇄회로 텔레비전, 공원, 하천, 신호등, 경사 정보를 반영한 코스 점수
- 사용자 프로필, 업적, 통계, 기록 공유
- 비공개, 친구 공개, 전체 공개 프로필 설정
- 친구 및 전체 사용자 랭킹
- 기록 이상 징후 검토, 경고, 정지, 증명 요청 알림을 위한 관리자 화면

## 실행 방법

```sh
flutter run --dart-define-from-file=config/dev.json
```

`config/dev.json`에는 Supabase URL과 공개 키가 들어 있어야 합니다. 새 환경에서는 `config/example.json`을 복사해 실제 값을 채운 뒤 실행합니다.
디버그 IO 환경에서는 앱이 `config/dev.json`을 자동으로 보완 로딩하지만, 웹 실행이나 배포 빌드에서는 위 실행 옵션처럼 빌드 설정을 명시해야 합니다.
Supabase Auth의 Redirect URLs에는 `runspot://login-callback`을 등록해야 이메일 확인과 소셜 로그인이 앱으로 돌아옵니다.
