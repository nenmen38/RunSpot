# 런스팟

실시간 지도에서 내 위치와 주변 러너를 확인하는 플러터 기반 러닝 앱입니다.

## 앱 개요

홈 화면은 실제 지도를 표시합니다. 위치 권한을 허용하면 내 위치를 표시하고 이동에 따라 갱신합니다.
코스 생성·프리셋 추천 기능은 제거했습니다.

## 주요 기능

- 내 현재 위치와 주변 러너 지도, 내 위치로 이동, 조회 반경 선택
- 위치 공유 켜기·끄기 및 러너 닉네임·거리 확인
- 러닝 종료 시 개인 기록 저장, 내 기록 목록과 상세, 날짜·거리·시간·평균 페이스 조회
- 비공개·친구 공개·전체 공개와 차단을 반영한 서버 조회
- 프로필, 소셜, 관리 화면은 유지하며 통계·랭킹·업적·관리 데이터는 기존 예시 데이터입니다.

홈의 러닝 시작·일시 정지·계속·종료 버튼으로 현재 러닝의 거리와 시간을 측정합니다.
종료 시 위치 공유를 중단하고 개인 기록을 저장한 뒤 결과를 표시합니다. 백그라운드 전환과 GPS 중단 시 측정은 일시 정지하며, 복귀 후 계속 버튼으로 재개합니다.
홈 상단의 시계 모양 `내 기록` 버튼 또는 종료 결과의 `내 기록` 버튼으로 목록을 엽니다. 최신 순으로 20개씩 표시하고 새로고침·더 보기·기록 상세를 제공합니다.
저장 실패 시 종료 결과를 유지하며 `저장 재시도`로 같은 기록을 다시 전송합니다. 서버는 사용자별 기록 식별자로 중복을 방지합니다.
미저장 결과는 현재 실행 중인 앱 메모리에만 유지됩니다. 앱을 종료하거나 로그아웃하기 전에 저장을 재시도해야 하며, 오프라인 보관과 앱 종료 후 측정 복구는 포함되지 않습니다.
개인 기록에는 경로 좌표를 저장하지 않으며, 서버 검증 전 측정값은 랭킹이나 공개 게시물로 자동 반영하지 않습니다. 러닝 초대·수락은 아직 포함되지 않습니다.

## 실행 방법

```sh
flutter run --dart-define-from-file=config/dev.json
```

`config/dev.json`에는 Supabase URL과 공개 키가 들어 있어야 합니다. 새 환경에서는 `config/example.json`을 복사해 실제 값을 채운 뒤 실행합니다.
디버그 IO 환경에서는 앱이 `config/dev.json`을 자동으로 보완 로딩하지만, 웹 실행이나 배포 빌드에서는 위 실행 옵션처럼 빌드 설정을 명시해야 합니다.
Supabase Auth의 Redirect URLs에는 `runspot://login-callback`을 등록해야 이메일 확인과 소셜 로그인이 앱으로 돌아옵니다.

## 지도와 위치 공유

- 지도는 `flutter_map`과 OpenStreetMap 타일을 사용합니다. 지도 API 키 없이 실행할 수 있습니다.
- 지도 배경은 밝은 저채도 색상으로 표시하며 내 위치와 러너 마커는 원래 색상을 유지합니다.
- 위치 공유는 기본으로 꺼져 있습니다. 공유를 켜려면 전화번호 인증, 닉네임 등록, 친구 또는 전체 공개 설정이 필요합니다.
- 서버에 `supabase/migrations/20261006000100_live_runner_map.sql`을 기존 마이그레이션 다음에 적용해야 주변 러너가 표시됩니다. 자세한 적용 안내는 `supabase/README.md`를 확인합니다.
- 기록 저장에는 `supabase/migrations/20261008000100_run_history.sql`을 적용해야 합니다. 기록은 전화번호 인증 여부와 관계없이 본인만 조회할 수 있습니다.
- 앱이 백그라운드로 가거나 공유를 끄면 공유를 중단합니다. 다시 앱을 열어도 자동으로 공유를 켜지 않습니다.
- 이동 시 최대 5초 간격으로 전송하고, 정지 상태에서도 15초마다 현재 위치를 갱신합니다. 2분간 갱신되지 않은 위치는 조회에서 제외됩니다.
- 비공개 실시간 채널에는 좌표나 사용자 ID를 보내지 않습니다. 변경 신호 수신 후 서버 조회를 통해 현재 권한을 다시 확인합니다.
- 에뮬레이터는 테스트 위치를 설정해야 현재 위치를 찾을 수 있습니다. 실제 두 기기에서 공유·이동·비공개 전환을 확인해야 합니다.
- 타일 사용은 [OpenStreetMap 정책](https://operations.osmfoundation.org/policies/tiles/)을 따릅니다. 타일 공급자를 변경할 때에는 `MAP_TILE_URL`, `MAP_ATTRIBUTION`, `MAP_ATTRIBUTION_URL`을 빌드 설정으로 함께 지정합니다.
