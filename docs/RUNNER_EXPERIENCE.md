# 러닝 기능 확장 및 검증 안내

## 앱에서 확인하는 경로

- 소셜 → 동네 러닝 모임: 지역·페이스 검색, 모집, 참가·취소, 일정 파일 공유, 출발 준비, 신고.
- 소셜 → 친구 초대: QR·링크, 7일 만료, 기존 링크 폐기. 링크는 대상 확인과 요청만 지원하며 상대방의 수락이 필요합니다.
- 프로필 → 나의 훈련 계획: 4주·12회 일정, 본인 기록 연결·해제. 기록 연결은 목표 달성을 자동 판정하지 않으며 실제 수행 여부를 사용자가 확인합니다.
- 소셜 → 크루 → 공동 목표: 크루장이 목표를 만들고 회원이 합산에 동의합니다. 참여 이후의 공개·검증 완료·300m 이상 기록만 반영합니다. 참가 취소·탈퇴하면 기여분을 제외합니다.
- 내 기록 → 상세 → 파일 내보내기: JSON 기록 파일 또는 GPX 경로 파일. 전체 경로가 포함됨을 공유 전에 안내합니다. GPX에 존재하지 않는 좌표별 시각을 추정해 넣지 않습니다.
- 내 기록 → 외부 기록 보관함: 뜀터 JSON 및 건강 앱의 최근 30일 달리기에서 선택한 기록 가져오기·삭제. 심박·칼로리는 업로드하지 않습니다. 외부 기록은 순위·보상·크루 목표에서 제외합니다. GPX 가져오기와 건강 앱으로 쓰기는 아직 지원하지 않습니다.
- 채팅: 실패한 메시지는 계정·서버·대화별로 기기에 보관합니다. 대화를 다시 열면 같은 요청 식별자로 재전송할 수 있습니다.
- 러닝 종료: 300m 미만도 개인 기록에 저장하거나 버릴 수 있습니다. 보상·순위의 기존 조건은 유지합니다.
- 주간 목표: 계정별 서버 저장과 기기 캐시를 사용합니다.

## 워치

애플워치와 Wear OS 갤럭시 워치용 동반 앱을 추가했습니다. 휴대전화에서 시작한 러닝의 거리·시간·페이스를 표시하고 일시정지·재개를 요청합니다. 종료·저장은 휴대전화에서 진행합니다. 워치 단독 GPS 측정 앱은 아닙니다. Wear OS 이전 타이젠 워치는 지원하지 않습니다.

연결이 15초 이상 갱신되지 않으면 조작을 비활성화합니다. 명령에 러닝 식별자를 넣어 늦게 도착한 명령이 다른 러닝에 영향을 주지 않게 합니다. 워치로 계정 정보·인증 토큰·경로를 보내지 않습니다.

- 애플워치: Xcode의 `RunSpotWatch` 스킴. 휴대전화 앱에 Watch 콘텐츠가 포함됩니다. iOS·watchOS 대상의 개발 팀과 서명을 맞춰 설치합니다.
- 갤럭시 워치: `cd android && ./gradlew :wear:assembleDebug`. 휴대전화 앱과 동일한 패키지·서명을 사용해야 데이터 계층이 연결됩니다.
- 출시 APK/AAB는 `android/key.properties`가 없으면 실패합니다. QA APK만 `-PrunspotQaSigning=true`로 개발 서명을 명시할 수 있고 QA 서명 AAB는 차단합니다.

물리 기기에서 화면 꺼짐, 블루투스 단절·복구, 앱 종료, 장시간 배터리 사용, 건강 데이터 실제 권한·동기화, 푸시 수신을 검증해야 합니다. 빌드 성공이 이 검증을 대체하지 않습니다. 실제 서명 키와 스토어의 건강 데이터 사용 신고도 출시 전에 필요합니다.

## 검증

- 전체 Flutter 회귀 테스트 및 정적 분석.
- SQL 테스트: 계정 격리, 모집 정원·권한·차단, 중복 요청, 훈련 기록 소유권, 크루 접근, 외부 기록의 보상 분리, 초대 링크 폐기.
- 파일 변환: 좌표·값 검사, JSON 왕복, 구간 보존, 중복 식별자.
- Apple Watch 시뮬레이터 빌드, Wear OS APK 빌드 및 휴대전화 Kotlin 컴파일.
- CI에 Android 휴대전화·Wear OS 디버그 빌드를 추가했습니다.
