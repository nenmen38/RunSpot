## 2. 외부 서비스 이용(처리 위탁·제공)

| 받는 곳 | 내용 | 시점 |
|---|---|---|
| Supabase | 계정, 기록, 게시판 등 앱 데이터 저장 | 앱 이용 시 |
| Google (Firebase) | Firebase 구성, 기기 푸시 토큰·일반 활동 알림, 정제된 오류 및 기본 충돌 진단 정보 | 알림 권한 허용 후 활동 알림 발송 시, 출시 빌드 오류 보고 시 |
| Google (Gemini API) | AI 러닝 피드백 생성에 필요한 러닝 기록 요약 | 이용자가 전송에 동의하고 피드백을 요청한 경우에만 |
| 카카오 | 소셜 로그인에 필요한 계정 식별 정보, 지도 화면에 필요한 위치·영역 정보 | 카카오 로그인 또는 지도 화면 이용 시 |
| 공공데이터포털(기상청·에어코리아 등) | 날씨·대기질 조회에 필요한 위치 구역 | 러닝 환경 조회 시 |

- 현재 연결된 Supabase 프로젝트의 데이터베이스·인증·저장소 리전은 싱가포르입니다. Supabase는 서비스 운영에 따라 미국으로도 데이터를 이전할 수 있다고 안내합니다. 출시 설정이 같은 프로젝트를 가리키는지와 실제 백업 보관 기간을 확인합니다. [국외 처리 안내](https://supabase.com/legal/privacy-resources/data-residency-and-transfers-faq) · [개인정보 문의](https://supabase.com/contact-us)
- Firebase Cloud Messaging, Crashlytics, Hosting은 Google의 글로벌 인프라를 사용합니다. Firebase는 오류 진단 자료의 경우 90일 뒤 삭제 절차를 시작하며, 푸시 서비스에 쓰는 Firebase 설치 ID는 개발자가 삭제를 요청한 뒤 180일 이내에 시스템에서 제거한다고 안내합니다. 공개 정책 웹사이트의 접속 IP도 악용 감지와 통계를 위해 처리할 수 있습니다. [Firebase 개인정보 처리 안내](https://firebase.google.com/support/privacy)
- Google Gemini의 처리 조건은 API를 호출하는 프로젝트에 적용되는 약관으로 확인합니다. Google은 무료 서비스에 민감정보를 입력하지 말라고 안내합니다.
- [ ] 실제 출시 환경을 기준으로 이전 항목, 국가, 시점과 방법, 이전받는 자와 연락처, 목적과 보관 기간, 이전을 거부하는 방법과 효과를 확정합니다.

## 3. 보관 기간과 파기

- 회원 탈퇴 시 계정, 프로필, 러닝 기록·경로, 친구·차단, 업적·경험치, 게시글·댓글·좋아요·사진을 지체 없이 삭제합니다. 앱 안의 **설정 → 회원 탈퇴**에서 직접 요청하거나, [웹 계정 삭제 요청 페이지](https://capstone-running-policy.web.app/account-deletion.html)에서 쓰리엔 운영팀에 요청할 수 있습니다. 웹 요청은 계정 소유권을 확인한 뒤 처리합니다.
- 운영 기록(관리자 조치·탈퇴 사실)은 처리 완료 후 180일이 지나면 파기합니다. 법정 보존과 진행 중 분쟁에 필요한 감사기록은 해당 사유가 종료될 때까지 별도로 보존합니다.
- 실시간 위치는 러닝 공유가 끝나면 삭제합니다.
- 푸시 기기 연결은 로그아웃·계정 삭제·서버 세션 삭제 시 제거하고, 마지막 갱신 후 30일이 지난 연결은 정리합니다. 발송 작업은 최대 하루 보관합니다.
- 24시간이 지난 미사용 게시판 사진은 자동 정리합니다. 신고 원문과 증빙 사진은 신고 처리 또는 관련 이의 제기가 끝난 뒤 90일이 지나면 파기합니다. 현재 게시물에 첨부된 사진은 게시물 보관 기준을 따릅니다.
- Firebase 진단 자료의 보관 기간과 국외 이전 사항은 운영 설정 및 제공업체 정책을 확인하여 확정합니다.
