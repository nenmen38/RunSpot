# 개인정보처리방침 (초안)

> 이 문서는 현재 앱 코드가 실제로 처리하는 정보를 기준으로 만든 **초안**입니다.
> `[ ]` 표시 항목을 채우고 법률 검토를 받은 뒤 게시하세요. 기능이 바뀌면 함께 고쳐야 합니다.

[운영자 이름](이하 "운영자")은 러닝 앱 [앱 이름](이하 "앱")을 운영하며 이용자의 개인정보를 다음과 같이 처리합니다.

## 1. 처리하는 정보와 목적

| 구분 | 항목 | 목적 |
|---|---|---|
| 계정 | 이메일 주소, 비밀번호(인증 서비스가 암호화해 보관), 닉네임 | 가입·로그인, 본인 확인, 소셜 기능 이용 |
| 선택 인증 | 휴대전화 번호 | 이용자가 선택한 경우의 본인 확인 |
| 러닝 기록 | 시작·종료 시각, 거리, 시간, 페이스, 고도, 구간 기록, 이동 경로(GPS 좌표), 종료 시점 기온 | 기록 저장·조회, 통계·업적·경험치, 기록 검증 |
| 실시간 위치 | 러닝 중 현재 위치 | 이용자가 설정한 공개 범위(친구·전체)에 따라 지도에 표시. 러닝을 멈추거나 끝내면 공유를 중단 |
| 건강 데이터 | 심박수, 활동 칼로리 (이용자가 연동한 경우) | 기기에서 러닝 기록과 함께 표시. **서버로 전송하지 않음** |
| 게시판 | 게시글·댓글·좋아요, 첨부 사진, 선택한 동네(시·군·구) | 게시판 운영, 동네 글 표시 |
| 소셜 | 친구 관계, 차단 목록, 신고 내용 | 친구·랭킹, 차단, 운영 정책 위반 처리 |
| 기기 | 앱 설정, 기기에 임시 보관하는 전송 대기 기록 | 오프라인 기록 보관 후 전송 |
| 활동 알림 | FCM 기기 토큰, 로그인 세션 연결, 알림 종류별 수신 설정 | 친구 요청·함께 달리기 초대·댓글 알림 전송 |
| 오류 진단 | 정제된 오류 분류·앱 코드 위치, 기본 기기·앱·충돌 정보 | 오류 분석과 서비스 안정성 개선. GPS·인증 정보·다트 예외 원문·사용자 로그는 추가 전송하지 않음 |

- 게시판 사진은 앱이 **촬영 위치 등 메타데이터를 제거하고 다시 저장한 뒤** 업로드합니다.
- 러닝 기록 공유 이미지의 배경 사진은 기기에서만 사용하고 서버에 올리지 않습니다.

## 3. 보관 기간과 파기

- 회원 탈퇴 시 계정, 프로필, 러닝 기록·경로, 친구·차단, 업적·경험치, 게시글·댓글·좋아요·사진을 지체 없이 삭제합니다. 앱 안의 **설정 → 회원 탈퇴**에서 직접 요청할 수 있습니다.
- 운영 기록(관리자 조치·탈퇴 사실)은 [ ]년 보관 후 파기합니다. [ ] 법령상 보관 의무가 있으면 적습니다.
- 실시간 위치는 러닝 공유가 끝나면 삭제합니다.
- 푸시 기기 연결은 로그아웃·계정 삭제·서버 세션 삭제 시 제거하고, 마지막 갱신 후 30일이 지난 연결은 정리합니다. 발송 작업은 최대 하루 보관합니다.
- 24시간이 지난 미사용 게시판 사진은 자동 정리합니다. 신고 원문에 보존된 사진은 정리 대상에서 제외하므로 신고 자료 보관 기간을 별도로 확정해야 합니다.
- Firebase 진단 자료의 보관 기간과 국외 이전 사항은 운영 설정 및 제공업체 정책을 확인하여 확정합니다.

## 4. 이용자의 권리

이용자는 언제든 개인정보 열람·정정·삭제·처리 정지를 요청할 수 있습니다. 닉네임·공개 범위·동네는 앱에서 직접 바꿀 수 있고, 위치 공개는 설정에서 끌 수 있습니다.
