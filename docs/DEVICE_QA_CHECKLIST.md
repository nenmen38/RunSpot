# 실기기 점검표

출시 전에 실제 안드로이드 폰에서 한 번씩 확인합니다. 각 항목은 **이렇게 해 보고 → 이렇게 보이면 정상**입니다.
문제가 있으면 항목 번호와 화면 사진(또는 `flutter run` 로그)을 함께 남겨 주세요.

준비

- 개발 빌드: `flutter build apk --profile --dart-define-from-file=config/dev.json` 로 만든 APK를 설치합니다.
- 서버: `supabase db push --linked` 와 `supabase functions deploy operations-worker` 를 마친 개발 프로젝트를 씁니다.
- 테스트 계정 2개(A, B)를 만들고 서로 친구를 맺어 둡니다. 가능하면 폰도 2대를 씁니다.

## 7. 알림

| # | 해 볼 것 | 정상 |
|---|---|---|
| 7-1 | B가 A에게 메시지·친구 요청·좋아요 | A 폰에 보낸 사람 이름과 내용이 담긴 알림, 누르면 해당 화면 |
| 7-2 | 설정 > 알림에서 항목 끄기 | 그 종류 알림이 더 오지 않음 |
| 7-3 | 러닝 응원 알림(아래 SQL로 바로 시험) | '러너가 운동화를 신고 기다리고 있어요 👟', 누르면 홈 |

러닝 응원 알림을 기다리지 않고 시험하려면 개발 프로젝트의 SQL Editor에서 실행합니다(1분 안에 도착).

```sql
insert into runspot_private.push_jobs(recipient_id, actor_id, kind, target_id, source_key)
select id, id, 'comeback', id, 'comeback:' || id || ':test-' || now()::text || ':3'
from auth.users where lower(email) = lower('여기에_내_로그인_이메일');
```

마지막 러닝이 3일 안에 있으면 '그사이 달림'으로 보고 보내지 않는 것이 정상입니다.

## 9. 집 근처 위치 숨기기·캐릭터 확장·프로필 카드 공유

| # | 해 볼 것 | 정상 |
|---|---|---|
| 9-1 | 설정 > '집·직장 근처 위치 숨기기' | 기본 '반경 300m 가림'. 끄기·200·300·500m 선택 |
| 9-2 | A가 집 앞에서 러닝 시작 + 위치 공유 켬 → 300m 밖으로 이동 | 집 앞에서는 B 지도에 A가 안 보이고, 300m를 벗어나면 보임. 다시 집 근처로 돌아오면 사라짐 |
| 9-3 | 러닝 기록 > 공유 카드 > 경로 포함 | 스위치 아래 '집 근처 보호: 출발·도착 300m 주변은 가려져요', 카드 경로의 양끝이 잘려 있음. 짧은 러닝은 '경로가 부족해요' 안내 |
| 9-4 | 상점 > '내 러너 캐릭터 꾸미기'에서 헤어·머리색·표정·반려동물·계절 의상 | 21종이 칸별로 나오고 미리보기가 머리·얼굴·곁에 선 동물로 확대됨 |
| 9-5 | 꾸미기 창의 탭(헤어스타일 → 머리색 → 표정 → 모자 … → 계절 의상 → 반려동물) | 11개 탭이 옆으로 밀려 보이고, 입으면 위 캐릭터에 바로 반영. 머리색은 헤어스타일을 입어야 보임 |
| 9-6 | 프로필 캐릭터 아래 '프로필 카드 공유' | 닉네임·레벨·이름표가 담긴 카드와 4개 버튼 |
| 9-7 | '이미지 저장' | 사진 앨범에 `ddimteo_runner_….png`로 저장(안드로이드 9 이하는 저장 권한 요청) |
| 9-8 | '공유하기' | 카카오톡·인스타그램 등 공유 창이 뜸 |
| 9-9 | '채팅으로 보내기' → 친구·대화방 고르기 | 선택한 상대에게 카드 사진이 도착하고 '○○에게 카드를 보냈어요' |
| 9-10 | '게시판에 올리기' | 게시판 탭으로 이동해 글쓰기가 카드 사진이 붙은 채로 열림. 등록하면 사진과 함께 올라감 |
