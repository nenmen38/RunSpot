# 앱 번역(한국어·영어)

앱 문구는 Flutter 표준 번역 방식(gen-l10n)을 씁니다.

- 기준 언어: `lib/l10n/app_ko.arb`(한국어), 영어: `lib/l10n/app_en.arb`
- 생성 코드: `lib/l10n/generated/`(직접 고치지 않습니다). `flutter pub get`·`flutter run` 때 자동으로 다시 만들어지며, 손으로 만들려면 `flutter gen-l10n`을 실행합니다.
- 화면에서 쓰기: `import '../../l10n/l10n.dart';` 후 `context.l10n.runStart`. 번역 설정이 없는 곳(테스트 화면 등)에서는 한국어가 나옵니다.
- 언어 선택: 설정 > 화면 > 언어(휴대폰 언어·한국어·English). 휴대폰 언어가 한국어가 아니면 영어로 보입니다.

## 번역된 화면

하단 메뉴, 러닝 버튼·상태·지표, 출발 카운트다운, 러닝 완료 화면, 오프라인 안내 띠, 언어 설정과 날짜·복사 같은 기본 위젯 문구.

## 문구를 옮기는 순서

1. 화면의 한국어 문구를 찾아 `app_ko.arb`에 키(영어 카멜표기)와 함께 넣고, 같은 키로 `app_en.arb`에 영어를 넣습니다.
2. 화면 코드의 문구를 `context.l10n.키`로 바꿉니다. 숫자가 들어가는 문구는 `{seconds}`처럼 자리표시를 씁니다.
3. `flutter gen-l10n` → `flutter test`로 확인합니다.

아직 번역하지 않은 화면(소셜·게시판·상점·설정 세부 등)은 영어를 골라도 한국어로 보입니다. 사용자 많은 화면부터 차례로 옮기면 됩니다.
